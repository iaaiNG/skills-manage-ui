# Skills Manager (Tauri)

Skills Manager Desktop Application built with Next.js and Tauri v2.

## Development

Run Next.js dev server with Tauri desktop window:

```bash
npm run tauri:dev
```

Or run Next.js web standalone dev server:

```bash
npm run dev
```

## Build

Build desktop application with Tauri:

```bash
npm run tauri:build
```
